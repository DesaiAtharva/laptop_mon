# Implementation Plan — Prompt P11: macOS Adapter, Packaging, and Permissions

## 1. Objectives & Scope
Adhering strictly to **`AGENTS.md`** and **`docs/spec/SPEC.md`** (§4.2 macOS row, §10.1, §15.1):
- **Requirements:**
  - `REQ-1-6`: MUST support macOS desktop agent behind the shared `agent/adapters/base.py` interface.
  - `REQ-4-1`: Agent core code must NEVER import OS-specific modules.
- **Edge Cases:**
  - `E14`: OS update or reboot (re-verify permissions and policy before resuming capture).
  - `E56`: OS permission denied or revoked (Screen Recording, Accessibility).
  - `E59`: Fast user switching (interactive console user session binding).
  - `E61`: Multiple monitors and display topology changes.
  - `E63`: macOS permission reset (graceful detection, no prompt loops, actionable instructions).

---

## 2. Architecture & Deliverables

### 2.1 macOS Adapter Architecture (`agent/adapters/macos/`)
- `agent/adapters/macos/macos_api.py`:
  - Native macOS bridge using `ctypes` bindings for CoreGraphics, AppKit / Foundation, IOKit, and ApplicationServices.
  - C-level function bindings with pure Python fallback for non-macOS test environments:
    - Foreground App: `NSWorkspace.sharedWorkspace.frontmostApplication` $\rightarrow$ `bundleIdentifier`.
    - Idle Time: `CGEventSourceSecondsSinceLastEventType(kCGEventSourceStateCombinedSessionState, kCGAnyInputEventType)`.
    - Screen Capture: `CGWindowListCreateImage` across `NSScreen.screens` bounded to resolution caps.
    - Permissions:
      - Screen Recording: `CGPreflightScreenCaptureAccess()` and `CGRequestScreenCaptureAccess()`.
      - Accessibility: `AXIsProcessTrusted()`.
    - Display Topology: Enumerates active displays, DPI scale factors, and resolution bounds (E61).
    - Session & User: Console user resolution via `SCDynamicStoreCopyConsoleUser` (E59).
- `agent/adapters/macos/adapter.py`:
  - `MacOSAdapter` implementing `OSAdapterProtocol`.
  - Exposes capabilities: `FOREGROUND_APP`, `IDLE_DETECTION`, `SESSION_LOCK`, `POWER_SLEEP`, `SCREEN_CAPTURE`, `PERMISSION_STATUS`, `MULTI_MONITOR`.
  - Implements anti-prompting loop guard: remembers if permission was already prompted to avoid infinite OS dialog popups.
  - Permission reset detection (E14, E63): detects when macOS OS update revokes TCC permissions and transitions capability to `PROMPT_NEEDED` / `DENIED` with user guidance.

### 2.2 Launchd Autostart & Packaging (`agent/packaging/`)
- `agent/packaging/launchd/com.laptopmon.agent.plist`:
  - User-session LaunchAgent configuring `KeepAlive`, `RunAtLoad`, and stdout/stderr paths.
- `agent/packaging/build_macos.py`:
  - Build pipeline producing `.app` bundle, codesigning with Developer ID Application, applying hardened runtime entitlements (`com.apple.security.cs.allow-jit`, `com.apple.security.automation.apple-events`), and packaging `.pkg` / `.dmg` installer.
- `docs/MACOS_SIGNING_AND_NOTARIZATION.md`:
  - Documented steps for Developer ID certificate setup, entitlements, Apple Notary API (`xcrun notarytool submit --wait`), and stapling (`xcrun stapler staple`).

### 2.3 Documentation & Manual Test Evidence
- `docs/test-evidence/macos.md`:
  - Manual verification test sheet for lock, sleep/wake notifications, fast user switching, multi-monitor topology, and permission reset handling.

### 2.4 Test Suite (`tests/test_p11_macos_adapter.py`)
- Automated unit and contract tests:
  - Protocol compliance check with `isinstance(adapter, OSAdapterProtocol)`.
  - Capability reporting.
  - Foreground bundle identifier extraction.
  - Idle time calculation.
  - Multi-monitor topology discovery and boundary scaling (E61).
  - Fast user switching and console session validation (E59).
  - Permission states (Screen Recording, Accessibility) and reset detection (E14, E56, E63).
