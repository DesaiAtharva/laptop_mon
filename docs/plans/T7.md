# T7 Implementation Plan — Edge-Case Sweep E01 to E100

> **Prompt:** T7 (Edge-case sweep E01 to E100)  
> **Playbook Section:** 5. Test prompts (T7)  
> **Specification Section:** §13 (Edge-case register E01–E100), §14.1, Appendix A  
> **Rulebook:** AGENTS.md  
> **Status:** Draft -> In Progress

---

## 1. Goal and Scope

The goal of Prompt T7 is to perform a comprehensive, exhaustive sweep of all 100 edge cases (`E01` to `E100`) defined in Specification §13:
1. Verify that every edge case has a dedicated test function named `test_E##_<description>`.
2. Confirm that every automated edge case test executes and passes against the codebase without workarounds or skipped tests.
3. Verify that platform-specific cases that cannot run in headless CI (e.g. secure desktop, fast user switching, display rotation, sleep/wake, Wayland compositors) have complete, documented manual test sheets in `docs/test-evidence/windows.md`, `macos.md`, and `linux.md`.
4. Produce `docs/test-evidence/edge-cases.md` containing a complete 100-row audit table:
   - ID
   - Edge case summary
   - Test function name (`test_E##_*`)
   - Test layer (e.g. Unit, Integration, Agent, API, Security, Fault Injection)
   - Test file location
   - Result (PASS / Limitation)
   - Evidence link
5. Update `TRACEABILITY.md` (updating REQ-13-1 and AC-3 to `done`).
6. Run `check_traceability.py` and the complete test suite.

## 2. Inventory and Mapping Strategy

All 100 edge cases from Specification §13 and `docs/EDGE_CASE_ASSIGNMENT.md`:
- **E01–E13:** Offline, crash loops, shutdown, recovery, uninstallation (`agent/core/`, `tests/test_p5_agent_core.py`, `tests/test_t4_fault_injection.py`)
- **E14–E16:** OS reboots, agent auto-updates, rollbacks (`agent/core/updater.py`, `tests/test_p7_updater_packaging.py`)
- **E17–E22:** Quota, disk full, SQLite corruption, orphan files, encryption key loss (`agent/core/spool.py`, `agent/core/journal.py`, `tests/test_p5_agent_core.py`, `tests/test_t4_fault_injection.py`)
- **E23–E30:** Device lifecycle, clock drift, DST changes, out-of-order events (`apps/ingestion/`, `apps/analytics/`, `tests/test_p2_devices_policies_ingestion.py`, `tests/test_p4_analytics_timeline_reports.py`)
- **E31–E40:** Ingestion duplicate payloads, rate limiting, credential revocation (`apps/ingestion/`, `apps/devices/`, `tests/test_p2_devices_policies_ingestion.py`, `tests/test_t5_security_tenant_isolation.py`)
- **E41–E48:** Tenancy, RBAC, team changes, session revocation, cross-tenant isolation (`apps/tenancy/`, `apps/rbac/`, `tests/test_p1_tenancy_rbac_audit.py`, `tests/test_t5_security_tenant_isolation.py`)
- **E49–E55:** Screenshot URLs, malware upload validation, S3 retention, exclusion rules (`apps/screenshots/`, `tests/test_p3_screenshots_storage_retention.py`, `tests/test_t5_security_tenant_isolation.py`)
- **E56–E65:** Platform adapters, permissions, lock, sleep, RDP, multi-monitor, Wayland, UAC (`agent/adapters/`, `tests/test_p6_windows_adapter.py`, `tests/test_p11_macos_adapter.py`, `tests/test_p12_linux_adapter.py`, `docs/test-evidence/windows.md`, `macos.md`, `linux.md`)
- **E66–E74:** Timeline intervals, app rules, gaps, DST, late event recalculations (`apps/analytics/timeline.py`, `metrics.py`, `tests/test_p4_analytics_timeline_reports.py`)
- **E75–E82:** Celery retries, database deadlocks, connection saturation, report budget (`apps/analytics/tasks.py`, `views.py`, `tests/test_p4_analytics_timeline_reports.py`, `tests/test_t4_fault_injection.py`, `tests/test_t6_perf_load_footprint.py`)
- **E83–E90:** Billing webhooks, email delivery, disaster recovery, secret scrubbing, legal hold (`apps/billing/`, `apps/tenancy/`, `apps/audit/`, `apps/screenshots/`, `tests/test_p9_billing_and_lifecycle.py`, `tests/test_p10_security_observability_dr.py`, `tests/test_t5_security_tenant_isolation.py`)
- **E91–E100:** Local admin tampering limitation, EDR allowlisting, monotonic reboots, battery saver, user switching, support access (`agent/`, `backend/`, `tests/test_t5_security_tenant_isolation.py`, `tests/test_t6_perf_load_footprint.py`, `docs/LIMITATIONS.md`)
