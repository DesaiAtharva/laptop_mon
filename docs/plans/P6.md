# Implementation Plan — P6: Windows Adapter

## Objective
Implement the production Windows desktop adapter in `agent/adapters/windows/` adhering to `AGENTS.md`, master spec (§4.2 Windows row, §10.1), and P6 prompt requirements.

## Scope & Deliverables
1. **Windows Adapter Implementation (`agent/adapters/windows/`)**:
   - `adapter.py`: `WindowsOSAdapter` implementing `OSAdapterProtocol` (`agent/adapters/base.py`).
   - `win32_api.py`: Pure `ctypes` bindings for Win32 API functions without heavy external dependencies:
     - Foreground window: `GetForegroundWindow`, `GetWindowThreadProcessId`, `OpenProcess`, `QueryFullProcessImageNameW`, `GetWindowTextW`.
     - WinEvent hook: `SetWinEventHook`, `UnhookWinEvent` for `EVENT_SYSTEM_FOREGROUND`.
     - Idle detection: `GetLastInputInfo`, `GetTickCount64`.
     - Session state & user: `WTSGetActiveConsoleSessionId`, `ProcessIdToSessionId`, `GetUserNameW`, `GetSystemMetrics(SM_REMOTESESSION)` (E60).
     - Screen & topology: `EnumDisplayMonitors`, `GetMonitorInfoW`, `GetSystemMetrics(SM_CXVIRTUALSCREEN, SM_CYVIRTUALSCREEN)` (E61, E95).
     - Desktop capture via Win32 GDI BitBlt (`CreateCompatibleDC`, `CreateCompatibleBitmap`, `BitBlt`, `GetDIBits`).
     - Secure desktop / UAC detection: desktop switch check via `OpenInputDesktop` (E64).
     - Single-instance mutex: `CreateMutexW` (`Global\LaptopMonitoringAgentSingleInstance`).
     - Autostart helper: Per-user registry Run key (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
2. **Safety, Non-Goals & Lightness Invariants**:
   - Zero bypass of secure desktop or UAC (E64: explicit safe skip).
   - Lock screen not captured by default (E57).
   - Remote desktop (RDP) detected via `SM_REMOTESESSION` (E60).
   - Multi-monitor bounding and downscaling limit to prevent memory spikes (E95).
   - No AV/EDR evasion, documented allowlisting and code signing (E92).
   - Pure ctypes standard library — no pywin32, PyQt, or heavy external C extensions needed.
3. **Documentation & Manual Test Sheet**:
   - `docs/test-evidence/windows.md`: Scripted manual test sheet covering lock, sleep, RDP, multi-monitor, and fast user switching.
   - `docs/LIMITATIONS.md`: Document UAC and Secure Desktop architectural boundary per spec.
4. **Automated Tests**:
   - `tests/test_p6_windows_adapter.py`: Contract tests against `OSAdapterProtocol`, automated Win32 API mock/live tests, multi-monitor scaling, secure desktop handling, and all assigned edge cases (E56–E61, E64, E66–E68, E92, E95, E98).
