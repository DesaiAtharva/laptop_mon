# Plan C1 — Application Lightness & Repository Cleanup

> **Prompt:** C1 — Remove unnecessary files and make the application light  
> **Playbook Rule:** Run only after T8 passes. Follow `AGENTS.md` lightness rules.  
> **Status:** Planned

---

## 1. Objectives

1. **Perform Exhaustive File Inventory:**
   - Catalog all files in the repository.
   - Categorize into:
     - **Necessary to run:** Source code, database migrations, configuration, deploy files, lockfiles, application assets.
     - **Necessary to maintain:** Tests (`tests/test_*.py`), `TRACEABILITY.md`, specification (`docs/spec/SPEC.md`), ADRs (`docs/adr/`), runbooks (`docs/runbooks/`), `docs/LIMITATIONS.md`, test evidence (`docs/test-evidence/`), perf baselines (`docs/perf/BASELINE.md`, `docs/perf/CAPACITY.md`), release readiness (`RELEASE_READINESS.md`).
     - **Deletion Candidates:** Scratch/temporary files (`.coverage`, `backend/dev_db.sqlite3`, `dist/`), unused fixtures, dead code, unused imports, caches.
2. **Execute Automated Tooling Audits:**
   - **Python dead code:** Run `vulture` across `backend` and `agent` (identify unused imports/dead variables).
   - **Python dependencies:** Validate declared dependencies via `deptry` and ADR budget (`docs/adr/agent-dependencies.md`).
   - **Frontend dependencies:** Run `depcheck` on `frontend/package.json` to verify no unused dependencies exist.
   - **Frontend bundle & code:** Minify production build (`npm run build`), verify bundle lightness (< 200 KB minified, < 60 KB gzipped).
   - **Asset reference check:** Verify no unreferenced static images or orphan assets exist.
3. **Produce Documentation:**
   - Create `docs/cleanup/CLEANUP_PLAN.md` documenting file categories, candidates, tool audit findings, and lightness evaluation.
4. **Implement Cleanups in One Dedicated Commit:**
   - Remove dead imports in `agent/adapters/fake/fake_adapter.py`, `agent/adapters/windows/win32_api.py`, `backend/apps/billing/serializers.py`, `backend/apps/billing/services.py`, and `backend/apps/screenshots/storage.py`.
   - Remove temporary coverage data (`.coverage`), empty local SQLite cache (`backend/dev_db.sqlite3`), and staging build output.
   - Provide minimal, production-grade Dockerfiles for `backend/Dockerfile` (multi-stage slim Python 3.12 running as non-root user `appuser`) and `frontend/Dockerfile` (multi-stage Node build -> Nginx alpine) matching `deploy/docker-compose.prod.yml`.
   - Provide `backend/requirements.txt` and `agent/requirements.txt` pinned to minimal required dependencies, matching CI (`.github/workflows/ci.yml`).
5. **Re-verify Footprint & Regressions:**
   - Re-run T6 footprint suite (`tests/test_t6_perf_load_footprint.py`) and compare against `docs/perf/BASELINE.md`.
   - Re-run full test suite (`python backend/manage.py test tests --settings=config.settings.testing` -> 332 tests).
   - Re-run `python scripts/check_traceability.py --final`.
   - Re-run `python scripts/check_migrations.py`.
6. **Deliver Final C1 Report:**
   - Report before-and-after numbers for:
     - File count
     - Repository size
     - Dependency count
     - Agent installer / package size
     - Agent idle CPU and memory
     - Backend image footprint
     - Frontend bundle size

---

## 2. Guardrails & Non-Negotiables

- **Never** delete or squash database migrations.
- **Never** delete or weaken any tests, the spec, `TRACEABILITY.md`, ADRs, runbooks, or test evidence.
- **Never** change runtime business logic or break edge cases E01–E100.
- All deletions and optimizations executed in a single dedicated commit.
