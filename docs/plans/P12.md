# Implementation Plan — P12: Linux Adapter, Packaging, and Permissions

## Objective
Implement the production Linux desktop agent adapter, systemd user service packaging, desktop secrets integration, and comprehensive edge-case handling per §4.2, §10.1, §15.1, and edge cases E22, E56, E60, E62, E65, E94.

## Scope & Architectural Alignment
- **Zero OS Imports in Core:** All X11, Wayland, D-Bus, and Linux-specific ctypes calls reside exclusively in `agent/adapters/linux/` behind `OSAdapterProtocol` defined in `agent/adapters/base.py`.
- **Session Types & Desktop Environments:**
  - Support X11 (`XDG_SESSION_TYPE=x11`) with full foreground app inspection (`_NET_ACTIVE_WINDOW`, `/proc/<pid>/cmdline`), idle tracking (`XScreenSaverQueryInfo`), and multi-monitor geometry (`XRandR`).
  - Support Wayland (`XDG_SESSION_TYPE=wayland`) with portal-based screen capture (`org.freedesktop.portal.Screenshot`) and capability flags indicating restricted foreground window access where compositors forbid direct window snooping (E62).
  - Explicitly detect headless (`DISPLAY`/`WAYLAND_DISPLAY` missing) and remote/VDI sessions (SSH, XRDP, VNC) without crashing (E60, E65).
- **System Events via D-Bus:**
  - Monitor `org.freedesktop.login1` (systemd-logind) for PrepareForSleep / PrepareForShutdown.
  - Monitor `org.freedesktop.ScreenSaver` for ActiveChanged (lock/unlock).
- **Desktop Secret Storage & Fallback (E22):**
  - Implement Secret Service API (`org.freedesktop.secrets`) client via D-Bus with safe local encrypted keyfile fallback under permissions 0600.
- **Autostart & Packaging:**
  - Systemd user service `~/.config/systemd/user/laptopmon-agent.service`.
  - `.deb` package builder (Debian/Ubuntu control, postinst, systemd unit) and portable `.tar.gz` distribution builder with SHA-256 checksums.

## Edge Cases
- **E22:** Encryption key unavailable / Secret Service daemon missing: fallback to secure local keyfile.
- **E56:** OS permission denied or revoked: Wayland portal user denial handled safely without crash loops.
- **E60:** Remote desktop or VDI (XRDP, VNC, SSH forwarding) detection.
- **E65:** Headless or unsupported desktop: adapter reports SessionType.HEADLESS and exposes empty/limited capabilities rather than failing silently.
- **E62:** Wayland and X11 capability mismatch: capability flags dynamically reflect compositor restrictions.
- **E94:** Compression differs by OS: verify JPEG / WebP compression byte format consistency across adapters.
