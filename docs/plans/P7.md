# Implementation Plan — P7: Packaging, Signing, Installer, Updater & Rollback

## Objective
Implement the agent packaging pipeline, release manifest distribution, atomic updater with rollback, and safe installer/uninstaller adhering to `AGENTS.md`, master spec (§4.1 updater, §15.1), and P7 prompt requirements.

## Scope & Deliverables
1. **Backend Release Manifest & Rollout API (`backend/apps/releases/`)**:
   - `models.py`: `AgentRelease` with `version`, `channel`, `sha256_checksum`, `signature`, `package_url`, `rollout_percentage`, `min_agent_version`, `max_agent_version`.
   - `views.py`:
     - `GET /api/agent/releases/latest/`: Serves signed manifest to enrolled agents based on channel, rollout percentage hashing, and version compatibility.
     - Admin CRUD endpoints (`/api/releases/`) with audit logging.
   - `urls.py`: Routed into backend URL tree.
2. **Agent Updater & Atomic Rollback Engine (`agent/core/updater.py`)**:
   - Downloads release package to a staging directory.
   - Verifies SHA-256 hash and cryptographic signature before staging (REQ-4-5).
   - Rejects tampered or mismatched packages.
   - Checks schema version compatibility before applying update.
   - Enforces prohibition of updates during shutdown (REQ-4-7).
   - Atomic swap using staged directory swap and backup rotation.
   - Self-test and automatic rollback (REQ-4-6, E15): If new version fails startup self-integrity check, automatically restores previous version without data loss or queue destruction.
   - OS update and reboot re-verification hook (E14).
   - Self-integrity verification at startup (E91).
3. **Installer & Uninstaller (`agent/installer/`)**:
   - `install.py`: Standalone installer supporting silent arguments (`/TOKEN=...`, `/SERVER=...`, `/QUIET`), setting autostart, and checking permissions.
   - `uninstall.py`: Uninstaller implementing pending-data safety policy (REQ-15-2, E13): verifies queue depth, blocks silent deletion, exports unacknowledged data on request.
4. **Packaging & Signing Pipeline (`agent/packaging/`)**:
   - `build_windows.py`: Packaging helper that builds standalone embedded runtime bundle, strips debug symbols and unused libraries, validates cold-start time and installed size against budget (< 60 MB).
   - `signing.py`: Code-signing helper with Authenticode timestamping, dev unsigned markers, and certificate verification.
   - `docs/SIGNING_AND_ALLOWLISTING.md`: Documentation for IT admins, EV certificates, and EDR allowlisting (E92).
5. **Limitations & Traceability**:
   - `docs/LIMITATIONS.md`: Add LIM-005 documenting that local root/admin can tamper with endpoint binaries (E91).
   - Update `TRACEABILITY.md` for REQ-4-5, REQ-4-6, REQ-4-7, REQ-15-1, REQ-15-2, E13, E14, E15, E16, E91, E92.
6. **Tests**:
   - `tests/test_p7_updater_packaging.py`: Comprehensive test suite testing all updater stages, hash tampering, interrupted swap, rollback, shutdown locking, installer silent arguments, and uninstaller pending data protection.
