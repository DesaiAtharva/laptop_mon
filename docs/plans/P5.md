# Implementation Plan — P5: Desktop Agent Core with Fake Adapter

## Objective
Build the agent core (`agent/core`) and the scriptable fake adapter (`agent/adapters/fake`) per `AGENTS.md`, master spec (§4, §5, §6, §10.1, §12.1, §2.1, §11.3), and the P5 build prompt.

## Scope & Deliverables
1. **Adapter Interface & Fake Adapter**:
   - `agent/adapters/base.py`: OS-neutral `OSAdapterProtocol` and capability definitions.
   - `agent/adapters/fake/fake_adapter.py`: Scriptable, deterministic adapter for all tests and fault injection.
2. **Agent Core Modules**:
   - `agent/core/crypto.py`: Authenticated encryption (AES-256-GCM) with OS secure store interface and key-loss fail-safe (E22).
   - `agent/core/journal.py`: SQLite journal with WAL durability, integrity checks, quarantine & recovery on corruption (E08, E09, E19), bounded queue limits, and explicit gaps (E17, E18, E97).
   - `agent/core/spool.py`: Two-phase encrypted screenshot spooling, atomic rename, orphan reconciliation (E20, E21), priority dropping (screenshots dropped before journal).
   - `agent/core/policy.py`: Offline policy cache, validity grace checks, fail-closed behavior on expiry/revocation (E01, E37, E38).
   - `agent/core/privacy_filter.py`: Pre-storage exclusions, window-title redaction/suppression, and password-manager capture prevention (E67, E68).
   - `agent/core/status.py`: State tracking, discovery when UI is closed (E11), authorized stop (E12), first-run acknowledgement enforcement (§2.1, §11.3).
   - `agent/core/diagnostics.py`: Secret-redacted logging (E88), support bundle export, heartbeat telemetry (§12.1), network health diagnostics (E04, E05).
   - `agent/core/sync.py`: Bounded batch upload, exponential backoff with jitter, Retry-After, batch splitting on 413, revocation handling on 403, strict local deletion only after confirmed server acceptance (REQ-6-1, E02, E03, E34, E35, E36).
   - `agent/core/lifecycle.py`: Bounded graceful shutdown (REQ-5-4, E07), unclean shutdown detection with gap reporting (E08), crash-loop circuit breaker (E10), uninstall hook (E13), monotonic boot segment tracking (E93), user association (E59, E98).
   - `agent/core/scheduler.py`: Event-driven and timer-based scheduling with battery-saver and lock/sleep backoff (E58, E96).
3. **Tests**:
   - `tests/test_p5_agent_core.py`: Thorough test suite covering all P5 requirements and edge cases (E01, E04–E13, E17–E27, E37, E38, E56, E59, E67, E68, E88, E93, E96, E97, E98).

## Architectural Invariants
- **Core has zero OS imports**: `agent/core` must never import `win32*`, `AppKit`, `Cocoa`, `ctypes` OS hooks, or platform-specific libraries.
- **Lightweight**: Pure Python standard library + standard `cryptography` AEAD. Zero heavy frameworks.
- **Fail closed & transparent**: Never invent data, never upload plaintext on missing keys, never silently delete pending data, never silently restart monitoring after explicit user stop.
