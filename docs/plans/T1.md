# Implementation Plan — T1: Test Baseline and Coverage

## Objective
Establish complete automated test baseline, measure branch coverage across all modules, enforce coverage thresholds per Spec §14.1, add targeted deep unit tests to close branch gaps, and produce evidence report in `docs/test-evidence/T1.md`.

## Coverage Targets (§14.1)

| Area | Target Branch Coverage | Key Modules |
|---|---|---|
| Tenant scoping | ≥ 90% | `backend/apps/tenancy/context.py`, `backend/apps/rbac/permissions.py` |
| Event ingestion | ≥ 90% | `backend/apps/ingestion/services.py`, `backend/apps/ingestion/views.py` |
| Timeline reconstruction | ≥ 90% | `backend/apps/analytics/timeline.py`, `backend/apps/analytics/metrics.py` |
| Agent journal and spool | ≥ 90% | `agent/core/journal.py`, `agent/core/spool.py`, `agent/core/sync.py` |
| Overall application | ≥ 80% | All backend and desktop agent core components |

## Execution Steps

1. **Baseline Measurement**:
   - Run complete suite with `coverage run --branch`.
   - Run frontend TypeScript validation and build (`tsc && vite build`).
   - Extract branch coverage report per module and overall.

2. **Targeted Deep Unit Tests (`tests/test_t1_coverage_baseline.py`)**:
   - **Policy Validation & Schema Invariants**: edge cases in app rule precedence, screenshot exclusion syntax, and capture window boundaries.
   - **Event Schemas & Strict Parsing**: invalid ISO-8601 formatting, NaN/infinite numbers, malicious strings, payload size limits.
   - **Interval Reconstruction & Math**: anomalous timestamp sequences, duplicate boundaries, microsecond drift, DST 23h/25h boundaries.
   - **Idempotency & Retry Exhaustion**: concurrent event batch deduplication, replay collision behavior, state transition locks.
   - **Retention & Legal Hold Priority**: active legal hold preventing deletion during expired retention sweeps.
   - **Screenshot State Transitions**: invalid transitions (e.g. verified -> pending), expired upload intents, quota exhaustion.
   - **Quota Math**: seat count boundaries, device count ceiling, storage gigabyte rollups.

3. **CI Coverage Configuration**:
   - Create/update `.coveragerc` specifying source paths, branch coverage enforcement, and omit rules (test files, migrations).

4. **Flakiness Audit & Resolution**:
   - Ensure all tests run deterministically with zero order dependencies or leaking temp directories.

5. **Evidence & Documentation**:
   - Generate `docs/test-evidence/T1.md` documenting test counts, execution runtimes, coverage tables, and closed gaps.
   - Update `TRACEABILITY.md` for `REQ-14-1` and `REQ-14-2`.
