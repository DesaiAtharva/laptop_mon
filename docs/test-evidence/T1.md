## 4. Deep Test Coverage Additions (`tests/test_t1_coverage_baseline.py`)

41 new deep branch unit tests were authored in `tests/test_t1_coverage_baseline.py` covering:

1. **Tenant Scoping & Negative Authorization (`TenantScopingComprehensiveTests`)**:
   - `test_cross_tenant_event_leak_prevention`: Proves events from tenant B are never returned to tenant A.
   - `test_suspended_tenant_rejected`: Proves queries under suspended tenant raise `TenantSuspended` (E43).
   - `test_deleted_tenant_rejected`: Proves queries under deleted tenant raise `TenantDeleted` (E44).
   - `test_unauthenticated_request_rejected`: Proves anonymous requests cannot resolve tenant context.
   - `test_user_not_member_of_tenant_rejected`: Proves non-members cannot query tenant.
   - `test_user_disabled_membership_rejected`: Proves disabled members are rejected.
   - `test_role_scoping_manager_vs_employee`: Proves role-based queryset filtering.
   - `test_auditor_and_org_admin_permissions`: Proves auditor and org admin permission boundaries.
   - `test_screenshot_permission_evaluation`: Proves screenshot access checks.

2. **Ingestion & Anomaly Boundary Tests (`IngestionDeepBoundaryTests`)**:
   - `test_invalid_timestamp_formats`: Rejects unparseable ISO-8601 strings.
   - `test_future_timestamp_rejected`: Rejects events dated beyond clock skew threshold (E27).
   - `test_payload_size_enforcement`: Rejects payloads exceeding maximum allowed bytes (E34).
   - `test_idempotency_concurrent_batch_replay`: Tests duplicate event batch replay deduplication (E02, E03).
   - `test_unassigned_device_event_handling`: Handles events from unassigned or newly enrolled devices.

3. **Timeline Engine Edge Cases (`TimelineReconstructionComprehensiveTests`)**:
   - `test_out_of_order_events`: Tests interval reconstruction when events arrive out of order (E28).
   - `test_telemetry_gap_on_missing_heartbeat`: Verifies explicit telemetry gaps are recorded rather than inferred activity (REQ-9-3).
   - `test_overlapping_app_intervals`: Verifies correct interval trimming on overlapping foreground events (E73).
   - `test_idle_end_without_idle_start`: Handles missing idle start event safely (E72).
   - `test_split_interval_at_midnight`: Verifies splitting intervals across local midnight boundaries (E71).
   - `test_dst_transition_interval_math`: Tests interval calculation across 23-hour and 25-hour DST days.

4. **Agent Journal & Spool Invariants (`AgentJournalAndSpoolComprehensiveTests`)**:
   - `test_journal_fifo_with_quota_headroom`: Validates FIFO pruning when disk quota is reached (REQ-5-2).
   - `test_journal_quarantine_corrupt_db`: Validates quarantine and recovery on corrupt SQLite database (E19).
   - `test_spool_startup_reconciliation`: Reconciles untracked image files on agent boot (E20, E21).
   - `test_spool_quota_drop_policy`: Validates dropping oldest screenshots when storage quota is reached.
   - `test_spool_read_and_delete_finalized`: Validates verified deletion protocol (REQ-6-1).

5. **Agent Scheduler Tick Orchestration (`SchedulerComprehensiveCoverageTests`)**:
   - `test_step_foreground_tick_transitions`: Validates foreground application transitions and privacy filtering (E67).
   - `test_step_idle_tick_transitions`: Validates idle start and idle end transitions (E70).
   - `test_step_screenshot_tick_guards`: Validates battery saver, permission, and policy guards (E68, E96).
   - `test_power_and_session_events`: Validates sleep, wake, lock, and unlock handling (E57, E58).
   - `test_step_sync_tick_defers_on_battery_saver`: Validates upload deferral under low power.

6. **Agent Sync Worker Invariants (`SyncWorkerTests`)**:
   - `test_sync_events_success_and_delete`: Tests event batch sync and local journal deletion upon 200/201 (REQ-6-1).
   - `test_sync_events_413_splits_batch`: Tests automatic batch splitting on 413 Payload Too Large (E34).
   - `test_sync_events_403_device_revocation`: Tests revocation handling and upload halting on 403 (E38).
   - `test_sync_events_429_backoff_and_permanent_error`: Tests exponential backoff with Retry-After and 400 bad event dropping (E35).
   - `test_sync_screenshots_two_phase_success`: Tests two-phase upload (intent -> storage PUT -> complete) (§6.2, REQ-6-3).
   - `test_sync_screenshots_storage_failure_reverts`: Tests retry revert on PUT failure.
   - `test_send_heartbeat_and_revocation`: Tests §12.1 heartbeat transmission and revocation.

7. **Analytics Reports Endpoints (`AnalyticsAndReportingViewTests`)**:
